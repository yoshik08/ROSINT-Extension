# Rosint Hidden History: developer reference

This is the technical reference for the extension: architecture, build,
packaging, store submission and verification. The repository README covers
what the extension does and how to install it.

## Layout

```
extension/
  shared/          all extension source (content scripts, worker, popup, renderer)
    assets/        Sora font (OFL) and icons, copied into each browser folder
  chrome/          manifest.json (Chrome MV3 service worker); build output lands here
  firefox/         manifest.json (Firefox MV3 event page); build output lands here
  scripts/         build, icons, screenshots and live checks
  tests/           unit + DOM tests (vitest/happy-dom), e2e suites
  dist/            build output: store packages, source archive, screenshots
src/               archive, retry and restriction clients shared with rosint.dev
```

Only `manifest.json` is tracked in `chrome/` and `firefox/`. Everything else
in those folders is generated by the build.

## Build

```bash
node extension/scripts/build.mjs     # or: npm run ext:build
```

The build has no dependencies beyond Node 20+. It:

1. bundles `shared/popup.js`, `shared/quietScript.js` (as `quiet.js`),
   `shared/content.js` and `shared/background.js` into classic scripts for
   each browser. Content scripts and Firefox's event page have no ES module
   support, so the build walks the import graph (including `../src`) and
   concatenates it inside one function scope per bundle (both content scripts
   share the page's isolated world, so bare top-level declarations would
   collide). Top-level names must be unique across the modules of a bundle;
   the build fails on a duplicate;
2. copies `popup.html` and `assets/` into `chrome/` and `firefox/`;
3. checks that both manifests have the same version and that every file a
   manifest references exists;
4. writes `dist/rosint-chrome.zip`, `dist/rosint-firefox.zip` (plus an
   identical unsigned `.xpi`) with `manifest.json` at the archive root;
5. writes `dist/rosint-source-<version>.zip`, the exact sources the bundles
   were built from, for Mozilla's source review.

Archives use fixed timestamps (override with `SOURCE_DATE_EPOCH`), so two
builds of the same sources are byte-identical.

## Load it unpacked

Chrome / Edge / Brave: `chrome://extensions` → Developer mode → **Load
unpacked** → select `extension/chrome/`.

Firefox: `about:debugging#/runtime/this-firefox` → **Load Temporary
Add-on…** → select `extension/firefox/manifest.json`. Temporary add-ons are
removed when Firefox restarts.

## Submitting to the stores

Run `npm run ext:check` first (lint, unit/DOM tests, build, `web-ext lint`).

**Chrome Web Store:** upload `dist/rosint-chrome.zip`. Store copy, permission
justifications and the privacy answers are in [`store/LISTING.md`](../store/LISTING.md).

**Firefox Add-ons:** upload `dist/rosint-firefox.zip` (not a zip of the
`firefox/` folder, which would put the manifest one level down). When asked
for source code, upload `dist/rosint-source-<version>.zip`; reviewers rebuild
it with `node extension/scripts/build.mjs` and get identical bundles.

The Firefox manifest declares `data_collection_permissions.required:
["browsingActivity"]`: the username of the profile being viewed is sent to the
public archives, and Mozilla counts that as transmitting browsing activity.

## How it works

1. **Content script** (`content.js`, `injector.js`) recognises profile URLs
   (`/user/<name>` and `/u/<name>`, plus `/submitted` and `/comments`) and
   re-runs on SPA navigation. A profile is treated as hidden when Reddit's
   hidden-history notice is on the page, or when `about.json` resolves and both
   listings are empty. Logged-out viewers get 403 on every JSON endpoint and a
   notice localised into their language, so the notice block itself (the
   profile feed's empty state with the waving-Snoo illustration) is also
   recognised, but only when the JSON check was refused. Suspended, missing or
   unreadable profiles are left alone.
2. **Worker** (`background.js`) makes every cross-origin request. It checks
   restrictions **first** (static hashes plus the removal service's
   `/api/config` and `/api/blocklist`, failing closed), then fetches one
   archive page of `t3_`/`t1_` ids, newest first. Arctic Shift's transient 422
   "Timeout", 429s, 5xx and hung requests (15s per attempt) are retried with
   backoff. PullPush gets one attempt and a 2s grace once Arctic has answered,
   and is skipped for five minutes after any failure. If both archives fail,
   the saved copy is served instead.
3. **Hydration** (content, same-origin) sends up to 100 fullnames per request
   to `/api/info.json` for the current live state, drops deleted and removed
   rows, and renders the rest. When the live lookup is refused (logged out),
   the archived snapshot is shown and labelled as such.
4. **Feed:** overview interleaves posts and comments by `created_utc`. The
   posts and comments tabs render one kind each. Infinite scroll fetches the
   next archive page, and the New/Hot/Top dropdown re-orders injected rows.

5. **Quiet Reddit** (`quietScript.js`, `quiet.js`) runs at `document_start` on
   every Reddit page. Its stylesheet applies at once; the rest waits for the
   saved setting (`settings.js`, on by default). A page counts as signed out
   only when Reddit drew something it shows signed-out viewers alone (the
   header's Log In button, Google One Tap, the sign-up rail, the NSFW gate).
   Then it removes the `configured-xpromo` dialogs (NSFW gate, app sheets),
   unblurs `shreddit-blurred-container[reason="nsfw"]`, clicks the over-18
   guard and sets `over18=true`, and closes `auth-flow-manager` modals (with
   Escape) and the Android sign-up sheet (by dropping `open`) unless a Log In
   or Sign Up click opened them. It records the result as attributes on
   `<html>` (`data-rosint-quiet`, `data-rosint-signed-out`,
   `data-rosint-nsfw-gate`) for the main content script.
6. **Archive fallback** (`fallback.js`, worker side `communityArchive.js`):
   signed out with Quiet Reddit on, a community or post page that Reddit
   answered with "not found" behind its NSFW gate gets Arctic Shift's copy:
   `/api/posts/search?subreddit=` newest first, or `/api/posts/ids` plus
   `/api/comments/search?link_id=`. Every author is checked against the
   removal list in the worker (fail closed), and removed or deleted rows are
   dropped in the page as they would be on Reddit.

Rendering details are in [RENDERING.md](./RENDERING.md).

## Shared modules

Archive and restriction logic is not reimplemented in the extension. It
imports the same modules rosint.dev uses:

| Concern | Module |
| --- | --- |
| Arctic Shift + PullPush requests, merge/dedupe, timestamp pagination | `src/archive.js` |
| Retry/backoff, `Retry-After`, batched parent-post lookups | `src/postLookup.js` |
| Removal-service client (fails closed) | `src/blocklistClient.js` |
| Static restriction hashes and the hash check | `src/blockedHashes.js`, `src/restrictions.js` |
| Username normalisation | `src/normalizeUsername.js` |

## Security model

* Archive text is never parsed as HTML. `markdown.js` builds DOM nodes, and a
  test fails the build if an HTML sink (`innerHTML`, `insertAdjacentHTML`,
  `eval`…) appears in the shared sources.
* Links keep only `http(s)` and Reddit-relative targets. Targets containing a
  backslash or control characters are dropped, because browsers read
  `/\host` as `//host`.
* Inline markdown nesting is capped and every delimiter scan is memoised, so
  hostile archive text renders in linear time.
* Rows live in shadow roots: Reddit's CSS can't restyle them, and they can't
  leak styles into Reddit.
* Only the extension's own popup can ask the worker for connection status or
  clear saved copies. Only reddit.com content scripts can ask for archive data.

## Permissions and privacy

* `host_permissions`: `www.reddit.com` (content scripts and same-origin reads),
  `arctic-shift.photon-reddit.com`, `api.pullpush.io`, `removal.rosint.dev`.
* `storage`: rows already restored are kept in `storage.local` (up to 80
  username/tab lists of 1,000 rows, plus parent post titles). They never sync
  and are read only after the restriction check passes. **Forget** in the
  popup clears them.
* No analytics and no remote code. Off Reddit profile pages the extension
  makes no requests, and on profiles it talks only to Reddit until one that
  hides its history is found. Quiet Reddit makes no requests at all; only
  its archive fallback, on a community or post Reddit refused, asks Arctic
  Shift. Opening the popup downloads the removal list to show service status.
* `storage` also holds the Quiet Reddit switch (`rosint:quiet`).

## Tests

```bash
npm run ext:test       # unit + DOM (vitest + happy-dom)
npm run ext:lint       # eslint + web-ext lint
npm run ext:check      # everything above plus a build
npx playwright install chromium
npm run ext:test:e2e   # packaged Chromium with controlled network responses
```

The e2e smoke test needs no Reddit account. It covers content-script/worker
messaging, fullname lookups, the logged-out (403) path and placement next to
Reddit's panel.

Live checks drive real browsers headless, so no window takes focus. They read
profile names from the environment:

```bash
export REDDIT_HIDDEN_USER=<a profile that hides its history>
export REDDIT_HIDDEN_USER_2=<another one this browser has never opened>

npm run ext:live:firefox -- --tabs overview,comments [--dark] [--lang de-DE]
npm run ext:live:spa           # Reddit's own tab clicks + back navigation
npm run ext:live:public        # a public profile (u/spez) must stay untouched
npm run ext:live:chrome        # site-access flow + real services, Chromium
npm run ext:outage             # saved copy during an archive outage
npm run ext:live:timing        # navigation → first row, cold and revisit
npm run ext:store:shots        # 1280x800 listing screenshots (dist/store)
npm run ext:popup:shots        # every popup state (dist/popup)
```

Automated Chromium gets Reddit's bot challenge, so the Chrome scripts use a
reddit.com-origin fixture page for Reddit's markup while talking to the real
removal service and archives. Firefox runs on the real reddit.com.

Please don't loop the live scripts: PullPush asks automated clients to back
off.

Quiet Reddit was verified by hand against real reddit.com, signed out, in
headless Firefox with the packaged add-on (Nov 2026): r/AskReddit (no One Tap,
no sign-up rail, a vote opens nothing, Log In still opens), an NSFW text
community (no gate, posts unblurred), an over-18-guarded community (opens
directly, media visible), an adult community and post Reddit refuses (filled
from Arctic Shift), and the Firefox for Android layout (One Tap, Open App and
the sign-up sheet gone). Reddit sometimes answers a fresh automated session
with "Prove your humanity"; load an ordinary page first.
